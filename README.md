# Touch A Heart x Kawika Lopez, holiday gift boxes (review site)

GitHub Pages site at https://darthkanaka.github.io/tah-gift-collab/ for Robin and Jenn's review. Hidden from search (robots.txt disallows everything, every page is noindex).

- `index.html` sends visitors on to `gifts/holiday-gift-boxes`, the final page in Stripe test mode, with a preview banner. Built by `build_preview.py` from the real page on the `holiday-gift-boxes` branch of kawikalopez-site; the checkout script's BASE_TEST Script Property points here so test orders return to this copy.
- `build_checkout_mockup.py` and `test_mockup.mjs` built and tested the design mockup (the vault copy is `projects/bakers-heart-checkout-mockup.html`).
- `sticker/` holds the mailer sticker design and print files.
